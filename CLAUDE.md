## Keeping the notes current

- When code changes a fact a note records (a path, a constant, an ID, a process date), update the note in the same commit.
- New knowledge about this repo goes in a new note in `.claude/memory/` with a one-line entry in its MEMORY.md, not in the per-machine auto memory under `~/.claude/projects/`.
- This repo is public. No secrets, credentials, email addresses, or names of reviewers or partner staff in notes.
