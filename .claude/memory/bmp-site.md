`qa/bmp/` replaces https://www.tahoebmp.org (ASP.NET, "Copyright 2021 Lake Tahoe EIP"), the TRPA Stormwater Management Program site. Built Oct. 20, 2026 from a full inventory of the old site. Production home, decided Oct. 20, 2026: `tools.trpa.gov/bmp/` (top-level `bmp/` in this repo, promoted with `git mv` when the must-fix list is closed); `bmp.trpa.gov` becomes a redirect to it, not a second Pages site (see `qa/bmp/docs/DEPLOY.md`, sections 0 to 2). Everything stays under `qa/` until then. Registered in `apps.json` as `bmpsite` (the site) and `bmpsearch` (the search tool), both beta, category eip.

Pages after the Oct. 21, 2026 content pass: index, get-certified (with the point-of-sale disclosure section), small-retrofit-plan (with a BMP Retrofit Permit section), about-bmps (titled BMP Requirements: why, what, the requirements list, rock sizes, conceptual drawings, commonly prescribed BMPs), maintenance, handbook, resources (registry sections installation, nrcs, training, maintenance, forms, landscaping, policy), gallery, faq, fertilizer, search, map. Contact and Realtors pages were removed at the program's request. Structure: one static HTML file per page with the header, nav, and footer copied into each (change them with a find and replace across `qa/bmp/*.html`); `assets/site.css` imports the shared `trpa-tokens.css` and the page uses `data-brand="eip"`; `assets/site.js` renders document lists, the handbook, the gallery, and the home page counts, and has `BMP.query()` (fetch with the JSONP fallback). Content lives in `data/documents.json` (84 items, `docBase` says where files are served from), `data/handbook.json` (chapters plus the Chapter 4 toolkit, 127 fact sheets and PDF/DWG drawings), and `data/gallery.json` (77 photos, migrated and resized into `assets/gallery/` by `scripts/fetch_legacy_images.py`, which needs Pillow from arcgispro-py3).

`search.html` is the rebuilt BMP Database search: one box that classifies the input and joins two services by APN. Parcel numbers and addresses come from `Parcels/FeatureServer/0` (61,271 rows; `PPNO` is the APN as a number, so a typed prefix becomes `PPNO >= lo AND PPNO < hi` ranges for the 8, 9, and 13 digit county formats, dash-insensitive; addresses match `HSE_NUMBR = n AND STR_NAME LIKE 'street%'` with the suffix dropped; `APO_ADDRESS`, `PSTL_TOWN`, `EXISTING_LANDUSE`, `YEAR_BUILT`, `PARCEL_ACRES`, `CATCHMENT`, `WATERSHED_NAME`, `FIREPD`, `PLAN_NAME` feed the detail panel; a house number of 0 means none). Owners and certificates come from `BMP_Status/MapServer/5` (fields `APN`, `ParcelStreet`, `BMPStatus` BMP/SCO/NOBMP, `CertNo`, `CertDate` as `yyyy/mm/dd` strings, `SourceCertNo`, `SiteConstraint` 'True'/'False', `AreaWide`, `AreaWidePlanName`, `EvaluationComplete` 0/1, `Rvkd`, `OwnerName`, `OWN_FULL`). The other half is fetched with `APN IN (...)` in chunks of 150; a 33-APN join took about 2 s on Oct. 20, 2026. `REPLACE()` is not supported in where clauses. `map.html` still queries `BMP_Status/5` directly with client-side dashed APN patterns (3-3-2, 3-3-3, 4-2-3-3). Certificates print on LT Info at `parcels.laketahoeinfo.org/parcels/<APN>`; the old toolkit's agent login and online evaluation requests are not replicated. Owner-name search is on for parity with the old tool and is easy to remove.

Documents: all PDFs, DWGs, and forms still point at tahoebmp.org (`docBase`). Measured Oct. 20, 2026: 292 files, 488 MB, of which the 2021 workshop MP4 is 282 MB and the complete handbook PDF 64 MB; everything else is about 143 MB. `scripts/fetch_documents.py --download` mirrors them into `documents/`. `Documents/BMPHandbook/Ch5_4_FertManPlnEx.pdf` was already a dead link on the old site.

Verified Oct. 20, 2026 (link check, legacy parity, axe on every page, search modes, 375 px layout); the report and the prioritized improvement plan are `qa/bmp/docs/IMPROVEMENTS.md`. Two axe findings remain and are AG Grid's own DOM (`aria-required-children` on `.ag-root`, `scrollable-region-focusable` on the viewports). `site.css` overrides `--gray-text` to `#5B6677` because the shared token fails AA on the `#F5F7FA` page background, and solid blue buttons use `--brand-primary-text`. The Claude browser pane requests a page-relative `trpa-tokens.css` on its own (404 in its console); a clean Chrome does not.

Program staff reviewed tahoebmp.org page by page on April 16, 2026 (keep-or-delete spreadsheet plus an annotated page map) for a planned move into trpa.gov; Communications now prefers a separate BMP site it can manage. The review reconciled with the rebuilt site is `qa/bmp/docs/CONTENT-PLAN.md`: cut Contact and Realtors (fold the disclosure into Get a Certificate), retitle "Why install BMPs?", regroup Resources (installation, training, maintenance, policy) and drop brochures, fire links, and forms, expand About BMPs into the requirements list, add an FAQ page, rewrite fertilizer from the staff draft. The fillable PDF problem is Adobe LiveCycle XFA: the maintenance logs and the interactive disclosure form are dynamic XFA and never open in browsers; the Small BMP Treatments Form is static XFA with an AcroForm fallback and works; the BMP Retrofit Application on tahoebmp.org is the Feb. 2021 version and the current one is the April 2024 Retrofit Packet on trpa.gov (`wp-content/uploads/documents/BMP_Retrofit_Application.pdf`). Microsoft Forms cannot take file uploads from outside the tenant, so Survey123 or Accela is the fit for maintenance documentation. Forms work started Oct. 21, 2026 (`qa/bmp/docs/FORMS.md`): `scripts/build_forms.py` generates `forms/bmp-maintenance-log.pdf` with reportlab as a 273-field AcroForm (20 BMP sections and 61 questions mirroring the 2016 XFA log); `scripts/build_survey123_forms.py` writes the XLSForms for BMP Maintenance Documentation and Request a BMP Evaluation into `forms/survey123/`, to be published from Survey123 Connect; `BMP.config.maintenanceForm` and `evaluationForm` in `assets/site.js` hold the published links and the pages fall back to email while empty. reportlab and openpyxl are in the arcgispro-py3 user site-packages, so run those scripts without `-I`. pypdf 4.3.1 in that environment fails with KeyError 0 on form dictionaries; verify AcroForm output from the raw bytes instead.

**How to apply:** Edit content in the JSON files, not the HTML, when it is a document, drawing, or photo. Keep the folder self-contained (relative links only) so it can move to its own repo. The footer's TRPA Tools link is `../../` and must become absolute when the folder leaves this repo.
