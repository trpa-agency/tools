Each working group keeps its own Environmental Improvement Program priority lists current here: an LTRA list for the annual Lake Tahoe Restoration Act request and an Other list for every other funding source.

  1. Baseline. The lists start where they ended last cycle: the latest list each working group sent through EIP Funding Priorities. That baseline is kept as FY27 and never changes.
  2. Changes. Choose your working group, click a project, and save. Every save is one record: the group, the project, the list, the priority, the request, the criteria, the note, and who saved it. The newest record for a project on a group's list is what counts, so nothing is ever overwritten and there is nothing to resend. Priority None takes a project off the list.
  3. Who can change what. Anyone with the link can save to any group's list, and every save carries a name. The record history shows what changed and when.
  4. Exports. Print master sheet is every group's list with totals. Print LTRA priority list drafts the public priority list document in last year's layout, with amounts from the LTRA lists; the text can be edited on the page before printing.

Project records come from the EIP Project Tracker through the nightly snapshot in trpa-agency/EIP. Only EIP projects in planning or implementation can be listed.
