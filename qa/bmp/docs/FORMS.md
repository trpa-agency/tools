# Forms

How the BMP program's forms are built and published, and why the old ones broke. Started Oct. 21, 2026.

## The rule

Fillable PDFs that must work in a browser are **AcroForms** made with Acrobat or generated by code. **LiveCycle Designer (XFA) forms do not open in Chrome, Edge, Firefox, or Safari**; they show a "Please wait..." page and only work in Adobe Reader. Adobe discontinued LiveCycle, the person who built TRPA's XFA forms has left, and nothing new should be built that way.

Submissions with attachments (photos, invoices, logs) are **web forms, not PDFs**. Microsoft Forms cannot accept file uploads from anyone outside the TRPA tenant, so property owners and contractors could not attach anything. Survey123 (public form, attachments, APN, results in the TRPA GIS next to the BMP Database) is the fit; Accela Citizen Access already handles Small BMP Retrofit Plans.

## Generated PDFs

`scripts/build_forms.py` draws each form with reportlab and adds the fields as standard AcroForm widgets, so the file opens and fills in every browser and prints cleanly. The layout and field names are in the script; change them there and rerun:

    "C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3\python.exe" scripts/build_forms.py

Outputs land in `forms/`. The site links them directly (`forms/bmp-maintenance-log.pdf`), so a rebuild is a commit, not an upload to another server.

Field names in the maintenance log follow `section_row_column` (for example `infiltration_trench_ok`), which keeps exports from Acrobat readable if staff ever collect filled copies.

## Survey123 forms

`scripts/build_survey123_forms.py` writes the two XLSForm workbooks. Each has the three standard sheets (`survey`, `choices`, `settings`). To publish:

1. Open Survey123 Connect (desktop), sign in to the TRPA ArcGIS Online organization, choose New survey, then File, and pick the `.xlsx`.
2. Check the preview on the right. Groups appear as pages; the APN question validates the four county formats; photo repeats allow up to 10 (maintenance) or 6 (evaluation).
3. Publish. Survey123 creates a hosted feature layer with one row per submission and the photos and files as attachments.
4. In the Survey123 website, under Collaborate, share the survey with Everyone (public) and copy the survey link. Sharing the results stays with the program group.
5. Put the link in `assets/site.js` (`BMP.config.maintenanceForm` and `BMP.config.evaluationForm`); the Maintenance page and the search's "Request an evaluation" button switch from the email path to the form when those values are set.

Edit the questions in the script, not in Connect, so the design stays in the repo; republishing from a changed XLSForm keeps the same survey and feature layer as long as the field names do not change (adding questions is fine; renaming is a schema change).

Later: the hosted feature layer can be joined to the BMP Database by APN, and a Survey123 webhook or a scheduled script can email the program when a submission arrives.

## Retiring the old files

When the Survey123 forms are live and the AcroForm log is linked, the legacy `Maintenance_Log_interactive_form.pdf` and `Maintenance_Log_static_form.pdf` can be removed from the old server, and the maintenance page's note about Adobe Reader goes away. The disclosure form stays as the static PDF until the program decides whether to rebuild it as an AcroForm (same script, one more spec) or move it into a web form.
